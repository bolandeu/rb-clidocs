
 Usage: clidocs docs [OPTIONS]

 Write the help of every command as one document for people: OpenCLI with the commands at the root.

 The document follows the help standard: each command has its summary, description and examples
 apart, and each option ends with its default and allowed values. The same version writes the same
 bytes. A viewer such as InSpectra renders it as HTML.

 Example: clidocs docs --out docs.json

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --out            FILE  Write the document to FILE (replaced when it exists); by default to       │
│                        stdout.                                                                   │
│ --json                 Emit machine-readable JSON output.                                        │
│ --quiet                Suppress non-essential output.                                            │
│ --verbose              Emit extra diagnostic output.                                             │
│ --help                 Show this message and exit.                                               │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
